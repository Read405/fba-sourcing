# fba-sourcing

A reusable sourcing system for reselling products, starting with Amazon FBA.
It evaluates candidates from any source (stores, websites, thrift, liquidation,
wholesale) through four gates, sell-ability, sell-through, profit, and risk, and
returns BUY / CHECK MANUALLY / WATCH / REJECT with every number sourced.

The full specification lives in [docs/brief.md](docs/brief.md).
